# logs/

Runtime logs generated by LockSense at execution time.

**Only this README is tracked in the repository.** All other files inside this folder are generated locally at runtime and must never be committed.

## Files

| File | Description |
|------|-------------|
| `locksense.log` | Current day's log. Rotated daily at midnight. |
| `locksense.log.YYYY-MM-DD` | Rotated log files kept up to `retention_days` days (default: 7). |

## Format

```
2026-09-04 15:42:00,123 [INFO] locksense.main - Message
```

## Configuration

```json
{
  "logging": {
    "level": "INFO",
    "retention_days": 7
  }
}
```

`level` accepts `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`.
